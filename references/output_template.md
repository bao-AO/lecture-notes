# 笔记模板与写法示例

最终产物是一份能直接拿来复习的 Markdown 笔记。结构固定，但每一节都要用连贯的讲解语写，不是要点堆砌。

## 一、文件命名与保存

- 文件名：`课程名-课堂笔记-YYYY-MM-DD.md`；课程名未知时用 `课堂笔记-YYYY-MM-DD.md`。
- 保存到当前工作区，交付时用 `present_files` 打开预览。
- 同一天同一门课有多段录音，合并成一份笔记，不要拆成几个文件。

## 二、结构骨架

按下面顺序输出，七节不全就说明笔记还没做完。

```markdown
# 课程名 · 课堂笔记（YYYY-MM-DD）

## 一句话概览
用两三句话说清：这节课讲什么、解决什么问题、结论是什么。

## 知识脉络
1. 起点：这节课从什么问题或背景出发。
2. 概念：引入的核心概念，以及它为什么必要。
3. 方法：怎么用这个概念解决问题，步骤是什么。
4. 例子：老师举的例子，说明方法怎么落地。
5. 结论：这节课的结论与它的适用边界。

## 重点清单

| 类别 | 内容 | 转写依据 | 优先级 |
| --- | --- | --- | --- |
| 定义 | … | 老师原话片段 | 必记 |

## 知识点详解
按重点逐条展开：定义 → 为什么需要它 → 怎么用 → 常见错误。

## 补充与延伸
- 补充：…（来源：…）

## 存疑与待确认
- 听不清／板书缺失／说法冲突／术语待确认，逐条列出。

## 术语表

| 术语 | 写法依据 | 一句话解释 |
| --- | --- | --- |
```

## 三、各节的写法要求

### 一句话概览

两三句，不罗列要点。要求：没听过课的人读完这三句，知道这节课在讲什么。

反例：本节介绍了定义、性质、计算方法和应用。
正例：这节课解决的是"给定一个不规则图形的边界，怎么算出它围出的面积"。老师先引出分割求和的想法，再用极限把它写成定积分，最后用两个例题说明什么时候该换积分次序。

### 知识脉络

- 编号步骤，4–8 步，每步 2–4 句。
- 每步开头交代"为什么讲到这里"，结尾留一个引子接下一步。
- 例子和学生的提问放在它们真实出现的位置，不要集中挪到末尾。
- 老师省略的推导写「此处推导未展开」，不补写。

### 重点清单

用表格，四列齐全（类别、内容、转写依据、优先级）。「转写依据」写老师原话片段，用于核对，不要写自己的转述。

### 知识点详解

每条重点一段，按"是什么 → 为什么 → 怎么用 → 容易错在哪"的顺序展开。公式要写清符号含义和成立条件。

### 补充与延伸

只放联网检索来的内容，每条都带来源名称或链接。课堂内容和补充内容必须能一眼分开。

### 存疑与待确认

四类必须写：转写听不清的、依赖板书或 PPT 而录音缺失的、课堂说法与检索资料冲突的、术语写法未确认的。这一节宁可写多，也不要为了笔记好看而省略。

### 术语表

只收本节课真正用到的术语，每条给一句话解释和写法依据（老师原话、检索确认，或标注未确认）。

## 四、三类内容的标注规则

| 内容来源 | 标注方式 |
| --- | --- |
| 课堂原话／原意 | 正文默认写法，必要时加引号保留老师原句 |
| 整理后的解释 | 用连贯语言重写，不加标注，但不得改变原意 |
| 联网补充 | 必须写成「补充：…（来源：…）」，并放在补充与延伸一节 |

绝不把检索来的说法写成老师的观点。老师讲的版本与检索结果冲突时，两者都保留并注明差异，不擅自选边。

## 五、语言要求

- 清理口语、语气词和重复，但保留老师举的例子和关键措辞。
- 句子短，多用"因为……所以……""先……再……"这类有推进关系的句式。
- 每个小节第一句先给总括，再展开细节。
- 不用"如上所述""综上所述"等空转连接词，用具体内容承接。

## 六、交付前检查

- 概览能让没听过课的人看懂这节课在讲什么吗？
- 脉络是不是一条连续的讲解，而不是七个并列段落？
- 重点清单每条都有老师原话依据吗？
- 三类内容有没有混在一起？
- 存疑区该写的都写了吗？
