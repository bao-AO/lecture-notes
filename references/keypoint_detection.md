# 重点识别与脉络重建

这份文档回答两个问题：课堂录音里，哪些内容必须写进笔记的重点清单；以及怎样把一节零散的课，重建成一条读得下去的知识脉络。

## 一、重点的判定信号

重点不是"老师讲得多的内容"，而是"老师希望学生记住的内容"。从转写文本里找下面三类信号。

### 1. 语言信号

- **明确标注**：「这个是重点」「考试必考」「这个一定要会」「记一下」「划一下」——直接判为必记。
- **重复**：同一内容在课中出现两次以上（包括换个说法再讲一遍）——高概率重点。
- **语气与节奏变化**：明显放慢、停顿、提高音量、突然点名提醒（「注意这里」）——判为重点。
- **自问自答**：老师抛出「为什么会这样」，随后自己给出答案——答案通常是理解型重点。
- **口头指向板书或屏幕**：「看这里」「看这个式子」——该处内容依赖视觉信息，转写里保留老师原话，同时在存疑区注明「此处指向板书，画面未包含在录音中」。

### 2. 结构信号

| 信号句式 | 判定类别 |
| --- | --- |
| 「X 是指……」「所谓 X，就是……」 | 定义 |
| 「第一步……第二步……」「做法是……」 | 方法 |
| 「公式是……」「由……可以推出」 | 公式 |
| 「很多同学会错在……」「不要和 X 混了」 | 易错点 |
| 「举个例子」「比如说」 | 例子 |
| 「所以……」「这就说明……」 | 结论 |

课末的整体回顾（「这节课我们讲了三件事」）是最可靠的重点骨架，优先采信。

### 3. 命题信号

老师提到考纲、真题、作业、下次课要检查的内容，或给出「必须掌握／了解即可」的分级时，按老师给的分级处理，不要自行提高要求。

## 二、分类与标注

每条重点必须带类别，类别决定它在笔记里怎么写：

- **定义**：写准原句意思，保留老师用的措辞，不换成教材的另一种说法。
- **方法**：写成可照着做的步骤，保留顺序和适用条件。
- **公式**：写清符号含义和成立条件，符号听不清就进存疑区。
- **易错点**：写清"错在哪、为什么错、正确做法"，这是复习时最值钱的部分。
- **例子**：保留老师的原例，可压缩但不换例。
- **结论**：写结论本身，以及它解决了什么问题。

## 三、采信边界

- 只采信老师确认过的内容。学生回答之后老师没有纠正的，不进重点清单。
- 学生的提问要保留，往往正暴露这节课的难点，但它属于脉络环节，不属于重点。
- 以下内容不进重点清单：点名、进度通知、纪律提醒、设备与教室状况、与课程无关的闲聊、纯语气词。

## 四、重点清单的字段

每条按四项写：**内容**、**类别**、**转写依据**（截取老师原话的片段）、**优先级**（必记／理解／了解）。

「转写依据」这一栏是为了可核对：任何一条重点，都能回到录音里的某句话。写不出依据的，就不要写进清单。

## 五、知识脉络的重建

重点清单回答"要记住什么"，脉络回答"这节课是怎么一步步走到结论的"。两者都要有，脉络不是清单的重新排序。

重建步骤：

1. **判断主线类型**：问题驱动（先抛问题再求解）、概念驱动（层层定义递进）、推导驱动（从公式推到底）、案例驱动（用一个例子串起全部概念）。判断出主线，才知道哪一步是主线上的，哪一步是补充。
2. **切分环节**：按话题切换把全课切成 4–8 个环节，顺序通常是：背景或问题 → 核心概念 → 方法与推导 → 例子 → 结论与应用。环节太多说明切得太碎，太少说明没切开。
3. **补衔接句**：每个环节开头补一句"为什么讲到这里"，例如「定义了 X 之后，下一个问题是怎么算出它的值」。衔接句要写自己的话，但不能改变课堂的推进方向。
4. **安置学生提问**：把提问放回它出现的位置，作为脉络里的一环，并写清老师如何回应。提问的位置本身就是难点位置的证据。
5. **处理跳跃**：老师省略的推导不要凭空补全。写「此处推导过程未在录音中展开」，不要用教材内容冒充课堂内容。
6. **保留例子**：老师举的例子是脉络里最有说服力的一环，位置不要挪动。

## 六、交付前自检

- 每条重点都能在转写里找到老师原话吗？
- 有没有把学生未经纠正的回答写成了知识点？
- 脉络读起来是一条连续的讲解，还是六个并列的段落？
- 每个环节之间有没有"为什么要讲这个"的交代？
- 板书缺失、推导跳跃、说话人靠语境推断的地方，是否都已标注？
